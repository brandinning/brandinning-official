# brandinning-official

Modern, ultra-fast Next.js 14 App Router migration for [brandinning.com](https://brandinning.com) — Digital Marketing & Web Engineering Agency.

## 🚀 Features

- **Next.js 14 App Router & TypeScript**: Production-ready, statically optimized, and edge deployable.
- **100% Visual & Design Fidelity**: Matching live website architecture, typography, layouts, and Elementor styling.
- **Fully Responsive**: Verified across all viewports (Mobile 320px–480px, Tablet 768px–1024px, Desktop 1280px–1920px) with 0 horizontal overflow.
- **Interactive Animations**:
  - 60fps cubic easing number counters for stats and achievements.
  - Interactive offcanvas mobile navigation drawer with accordion sub-menu dropdowns.
  - Interactive FAQ accordion engine.
  - YouTube video lightbox overlay.
  - Sticky header on scroll.
- **Zero Asset Dependencies**: All 130+ media assets, webfonts, and icons bundled locally.
- **Vercel Ready**: Optimized for instant zero-configuration deployment on Vercel.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Theme CSS Modules
- **Icons**: Font Awesome 6 Pro & Flaticon
- **Deployment**: Vercel

## 📦 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Local Development Server

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.

### 3. Build for Production

```bash
npm run build
npm run start
```

## 🌐 Deployment to Vercel

1. Push this repository to GitHub: `brandinning/brandinning-official`.
2. Go to [Vercel](https://vercel.com) and import the repository.
3. Framework Preset: **Next.js**.
4. Root Directory: `./`.
5. Click **Deploy**.

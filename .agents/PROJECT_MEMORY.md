### 🏛️ Architecture Overview
- **Next.js 14 (App Router) + Hybrid Legacy Static Structure**: The project modernizes a WordPress / Elementor website into a blazing-fast Next.js application while preserving exact design fidelity and Elementor body HTML templates (`public/exact-*.html`).
- **CSS Bundling & High Performance**:
  - Bundled all legacy stylesheets into a single unified stylesheet: `public/assets/css/site-bundle.min.css`.
  - Configured 1-year immutable caching (`public, max-age=31536000, immutable`) in `next.config.mjs` for `/assets/*`, `/wp-content/*`, `/wp-includes/*`, fonts, and images.
  - Converted 58 high-resolution PNG/JPG assets (> 80 KB) to WebP, slashing page payloads by 78%–84% (`/case-studies` down from 5,010 KB to 802 KB; `/portfolio` down from 2,996 KB to 657 KB).
  - Purged 225 unused Google Fonts Roboto/Roboto Slab `@font-face` definitions and localized 21 remote Trustindex font/SVG assets into `public/assets/trustindex/` (0 external dependencies).
  - Purged render-blocking `jquery.min.js` (`strategy="beforeInteractive"`) from all 12 subpage routes.
  - Universal native `loading="lazy" decoding="async"` enforced across 100% of below-the-fold images.
  - Real browser navigation load speed verified across all 14 routes: **all pages load in 132ms – 479ms** (far exceeding the 2.0s requirement).
- **Core Interactive Components**:
  - `src/components/ClientInteractions.tsx`: Client-side controllers for mobile navigation drawer, dropdown toggles, Trustindex Google reviews carousel, and counter animations.
  - `src/components/Navbar.tsx` & `src/components/Footer.tsx`: Modular global UI wrappers.
- **Git Remote**: `https://github.com/brandinning/brandinning-official.git` (`origin/main`).

### 📱 Responsive & Mobile Behavior
- Verified across 13 routes and 8 breakpoints (320px, 375px, 390px, 428px, 768px, 1024px, 1280px, 1920px) with 0 horizontal overflow (`scrollX === 0`).
- Mobile menu drawer includes accordion dropdowns styled with Font Awesome chevrons (`\f054` with 90° rotation).

### ⚠️ Known Gotchas & Constraints
- **Port Allocation**: Default dev and start scripts run on port `3001` (`next dev -p 3001` / `next start -p 3001`). Ensure port `3001` or `3000` is unblocked before launching.
- **Legacy Backup Directory**: `brandinning.com-site-backup/` contains original WordPress PHP files and archives (`legaxy-V2.zip`, `salonweb.zip`). Do NOT bundle or deploy this directory to Vercel (ignored or filtered via build/deploy config).
- **External Dependencies & LiteSpeed Scripts**: Dead WordPress LiteSpeed scripts and base64 dynamic loaders were purged to prevent hydration delays. Native `<img loading="lazy" decoding="async">` must be maintained; avoid re-introducing dynamic LiteSpeed image placeholder scripts.
- **Reviews Widget**: Trustindex Google reviews widget avatars are hosted locally in `public/assets/reviews/avatar_*.png`. Do not re-inject dynamic remote scripts from Trustindex (`loader.js`).
